# SLSFC Digital Design System — Color

> SLSFC Digital Design System **v1.0** — implementation snapshot.
> Authoring source: the hosted SLSFC Digital Design System (https://claude.ai/artifact/XJgvEM7VTUzrAbjbswy9fK), version `1790961796-c84a`, approved 2026-10-02.
> Do not edit this file to change the design system. Change the hosted system first, then re-sync. See `brand/README.md`.

Canonical brand values come from SLSFC_Crest_Master_RGB.ai: navy #042644 and orange #FC4B08. orange-deep and crest-white are colors inside the crest artwork, kept for reference and narrow UI use, not general brand colors. slate and paper come from the identity boards. Every other value is a digital addition. Light is the 'away kit' (white ground); dark is the 'home kit' (navy ground).

Themes: **Light (Away)** is the default; **Dark (Home)** is the alternate.

## Brand values

| Token | Value | Usage |
|---|---|---|
| `navy` | `#042644` | Brand navy — the crest field, from the master crest. The club's anchor color: headlines on light grounds, the dark-theme page, bands, the home kit. Supersedes the boards' #082A4A / #08244A. |
| `navy-deep` | `#021A30` | Digital addition, a darker step of navy. Label color on orange fills (5.2:1 on orange) and the dark-theme band. Never a substitute for navy in the crest or logo lockups. |
| `orange` | `#FC4B08` | Brand orange — the crest's tail and outer border, from the master crest. Supersedes the boards' #F15A24. Fills, accent bars, link underlines, large display type (24px+), icons and the focus ring. Not body-size text (3.4:1 on white): text stays ink or ink-muted. |
| `orange-deep` | `#C93008` | Shading inside the crest artwork (master crest). Not a general brand color. Approved UI use, limited to one place: the light-theme value of accent-text, the orange soft Tag label (4.8:1 on accent-soft). Never a fill. |
| `crest-white` | `#F8F8F9` | The white inside the master crest. Used only where a flat recreation of crest colors is needed (print specs); UI uses white. |
| `white` | `#FFFFFF` | Pure white from the boards. Light-theme page and card ground; text on navy and on band. |
| `slate` | `#A7B0B8` | Board slate (#A7B0B8; the kit board's '#A78088' is a typo for this). Mono crest tint, muted text on navy (7.0:1), dividers on dark grounds. Never text on white (2.2:1). |
| `paper` | `#F3F4F3` | The cool off-white ground of the identity boards (sampled). Alternate section ground in the light theme. |

## Semantic tokens

Build pages from these, not from the brand values. Aliases are shown in braces.

| Token | Light (Away) | Dark (Home) | Usage |
|---|---|---|---|
| `surface` | `{white}` → `#FFFFFF` | `{navy}` → `#042644` | Page background. |
| `surface-alt` | `{paper}` → `#F3F4F3` | `#0A2E50` | Alternating page sections, table stripes, input wells. |
| `surface-raised` | `{white}` → `#FFFFFF` | `#0E355C` | Cards, menus, dialogs. In light it relies on line or shadow-sm to separate from surface. |
| `band` | `{navy}` → `#042644` | `{navy-deep}` → `#021A30` | Full-bleed navy bands: hero, values band, footer. Text on it is on-band; accents are orange. |
| `on-band` | `{white}` → `#FFFFFF` | `{white}` → `#FFFFFF` | Text and icons on band (15.4:1 light, 17:1 dark). |
| `on-band-muted` | `{slate}` → `#A7B0B8` | `{slate}` → `#A7B0B8` | Secondary text on band (7.0:1 light). |
| `line` | `#DDE2E7` | `#22466B` | Hairline dividers and card outlines. Decorative only — never the sole boundary of a control. |
| `line-strong` | `#77838F` | `#6F8CA8` | Input and checkbox borders, any border that defines a control (3.9:1 on white, 3.5:1 on paper; 3.6:1 on surface-raised dark). |
| `ink` | `{navy}` → `#042644` | `{white}` → `#FFFFFF` | Primary text and headlines on surface, surface-alt and surface-raised in both themes (light 13.9:1 or better; dark 12.5:1 or better). Also links, ghost actions and nav links. |
| `ink-muted` | `#4F5D6B` | `{slate}` → `#A7B0B8` | Secondary text, metadata, captions and eyebrows on surface, surface-alt and surface-raised (light 6.1:1 or better; dark 5.7:1 or better). |
| `accent` | `{orange}` → `#FC4B08` | `{orange}` → `#FC4B08` | Brand orange as a mark: accent bars, link underlines, active-nav bar, icons, stripes, large display numerals. Not for body-size text. |
| `accent-text` | `{orange-deep}` → `#C93008` | `#FF8A50` | Approved for the orange soft Tag label only, on accent-soft (light 4.8:1, dark 6.1:1). Not for eyebrows, links or navigation — those use ink or ink-muted. |
| `accent-soft` | `#FFF0E8` | `#4A1E10` | Ground of the orange Tag, behind accent-text. |
| `action` | `{orange}` → `#FC4B08` | `{orange}` → `#FC4B08` | Primary button fill. One primary action per view. |
| `action-hover` | `#FF6A2E` | `#FF6A2E` | Primary button hover fill. |
| `on-action` | `{navy-deep}` → `#021A30` | `{navy-deep}` → `#021A30` | Label on action and action-hover (5.2:1 / 6.2:1). Never white on orange: 3.4:1 fails at button size. |
| `focus-ring` | `{orange}` → `#FC4B08` | `{orange}` → `#FC4B08` | Keyboard focus: 2px gap in the surface color, then a solid 2px orange ring (3.4:1 on white, 3.1:1 on paper, 4.5:1 on navy, 3.6:1 on surface-raised dark). |
| `success` | `#17784A` | `#5FD39A` | Status: 'On', confirmed, registered. Always with a word. On the surfaces and success-soft. |
| `success-soft` | `#E8F3EC` | `#123F2E` | Ground behind success text. |
| `caution` | `#8A5A00` | `#F2C14E` | Status: weather watch, limited spots, waitlist. Always with a word. On the surfaces and caution-soft. |
| `caution-soft` | `#FFF4D6` | `#3D300C` | Ground behind caution text. |
| `danger` | `#B4183C` | `#FF8597` | Status: cancelled, form errors. A crimson kept well apart from brand orange in lightness; always paired with a word or icon so it never relies on hue. On the surfaces and danger-soft. |
| `danger-soft` | `#FCE8EC` | `#5A1A2A` | Ground behind danger text. |
