# SLSFC Digital Design System — Component Guidelines

> SLSFC Digital Design System **v1.0** — implementation snapshot.
> Authoring source: the hosted SLSFC Digital Design System (https://claude.ai/artifact/XJgvEM7VTUzrAbjbswy9fK), version `1790961796-c84a`, approved 2026-10-02.
> Do not edit this file to change the design system. Change the hosted system first, then re-sync. See `brand/README.md`.

These are the approved component patterns. The hosted system also carries a React 18 reference build (`window.SLSFC`), which is not part of this snapshot; the website will implement these patterns in Elementor in a later, approved phase.

## SiteHeader

The site bar: crest and club name at left, uppercase nav, one orange Register button.

- **Provide:** `crestSrc` (the `slsfc-crest.svg` asset), `links` (`{label, href, active}`), `cta`; optional `name` (default "Squirrels", the brand expression, set uppercase) and `tagline` (default "St. Louis Squirrel Football Club", the formal name).
- The crest renders at 48px tall — never below `crest-min` (32px).
- Nav links are `ink`. The active link gets a 3px orange bar; hover shows a 3px `line-strong` bar. Under 760px the nav hides; supply your own menu button.
- The name lockup here is set in type (display, italic 800). It is not the lettered SQUIRRELS wordmark; replace the lockup with the wordmark artwork when it exists, and never set it in Barlow Condensed after that.

## Button

The club's call to action — orange `primary` for the one thing we want a parent to do on a view (usually Register), navy-outline `secondary` for everything else.

- **Provide:** `children` (a short verb phrase, set uppercase by the component), `variant`, optional `size="lg"` for heroes, optional `href` to render a link.
- `primary` fills with `action` and labels in `on-action` (navy-deep). Never white text on orange.
- On a navy `band`, use `inverse` (white outline) for secondary actions; `primary` still works there.
- `ghost` is a navy text action with an orange underline for low-weight links such as "Season calendar". On a band it turns white.
- Height is `control-height` (44px), the minimum touch target. Radius `radius-sm`.
- Do: one `primary` per view. Don't: stack two orange buttons side by side, or use a button for navigation inside running text.

## Tag

A short uppercase label for age groups, home/away and match or registration status.

- **Provide:** `children` (one or two words) and `tone`.
- `neutral` — age groups, categories. `navy` — Home. `orange` — new or featured (the one approved use of `accent-text`: orange-deep #C93008 text on `accent-soft`, 4.8:1). `success` — On / Open. `caution` — Weather watch / Few spots. `danger` — Cancelled / Closed.
- Status tones add a square dot and always carry a word, so status never depends on color alone.
- Don't use `orange` and `danger` side by side for different meanings; `danger` is reserved for cancellations and errors.

## SectionHeading

The board-derived heading block: a wide-tracked eyebrow in `ink-muted`, the short orange accent bar, an uppercase condensed title and an optional lead paragraph.

- **Provide:** `title`; optional `eyebrow`, `intro`, `level` (default 2), `align` (`left` default, `center` for landing heroes), `size="xl"` for page titles.
- Inside a `band` add the `sq-onband` class on the container; colors switch to `on-band` and `on-band-muted`.
- Keep eyebrows to one to three words. Titles are short and declarative ("Find the right team"). An exclamation mark is fine for a genuine celebration, not as a habit.

## ProgramCard

One program or age group: big orange age numeral, condensed title, a sentence, two to four facts and a single action.

- **Provide:** `ageGroup` ("U8", "U9–U10"), `title`, optional `description` (one sentence), `meta` (2–4 facts), `status` (`{tone, label}` using Tag tones) and `cta`.
- Lay cards in a grid with `space-6` gutters on `surface-alt` so the white cards separate.
- The orange top edge is the accent bar; don't add a colored side border.
- Use `cta.variant: 'primary'` only when registration is open for that card; otherwise `secondary`.

## FixtureRow

A single match on the schedule: navy date block, our team vs/at the opponent, time and venue, Home/Away tag, and status or final score.

- **Provide:** `date` (`{weekday, day, month}`, uppercase short forms), `team`, `opponent`, `homeAway`, optional `time`, `venue`, `score` (ours first, en dash: "3–1") and `status`.
- Wrap rows in a container with `role="list"`; each row is a listitem.
- Weather calls use `status` with tone `caution` (watch) or `danger` (cancelled); always say the word.
- Stacks to two columns under 560px.

## ValuesBand

A full-bleed navy band stating the club's three values, topped by the orange/white kit-collar trim.

- **Provide:** optional `values` (`{title, text}`); defaults to Community, Character, Confidence with no body text.
- Keep the three values in that order. Body lines are one sentence each, in plain language.
- Use once per page at most — typically home and About.
